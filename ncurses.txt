Using ncurses in Linux console c program

- Install the library: $ sudo apt-get install ncurses-dev
- To compile: $ gcc -o hello hello.c -lncurses

Basis:

#include <ncurses.h>
int main(){
  initscr();
  printw("Hello World!");
  wrefresh(curscr);  // adapt output to terminal, like windows console.
  getch();
  endwin();
  return 0;
}

Move cursor:

move(12, (40-5));  // center the string 'Hello World!' on a  80, 25 screen.  format is: move(y, x);
To combine move and print use mvprint(y, x, string).
